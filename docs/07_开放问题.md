## 建议的决策顺序

1. **O4**（位移参考）——不解决，P5 无法开工。建议先选"人工标记"（方案 a）跑通，再考虑增强。
2. **O3 / O6**（数据表来源）——P2/P3 开工前必须定，否则识别层无根。
3. **O7**（执行器）——P6 前定即可，本版串口 WARN 不阻塞。
4. **O1**（合规）——只要产品化就必须过，越早越好。
5. **O2**（P7 立项）——最后定。
