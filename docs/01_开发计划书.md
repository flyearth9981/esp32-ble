## 1. 目标

基于 ESP32-C5 构建便携 BLE 反追踪探测器：

1. 监听周围 BLE 广播（被动 + 主动），解析广播报文；
2. 识别设备厂商，重点识别自述为 Apple 的设备（Company ID 0x004C）；
3. 识别被用于位置追踪的设备类别（Find My / AirTag、Tile、SmartTag 等）；
4. 在单次通电会话内，对"持续跟随佩戴者移动"的可疑设备做启发式判定并告警。

## 2. 非目标

不支持经典蓝牙（A2DP/SPP/HFP）· 不做 AoA/AoD 测向 · 不解密 Apple 加密载荷 · 本版不做持久化存储 · 不做云/手机 App · 不具备产品级取证效力。

## 4. 硬约束

- **C1 [INFERRED, HIGH]** 跟随判定仅限单次通电的 RAM 滚动窗口，重启清零，无历史。
- **C2 [INFERRED, HIGH]** 跟随判定要求佩戴者本人移动；板子固定时只可做"持续存在"检测。
- **C3 [KNOWN, HIGH]** 本版告警为串口文本，对终端用户无效，属过渡形态。
- **C4 [INFERRED, MED]** DevKit + 充电宝随身 = 研发验证级（D10 已确认接受）。真可穿戴须 P7 定制板 + 电池。

## 5. 平台与能力边界

### 5.1 硬件
- ESP32-C5-WROOM-1：2.4GHz BLE 5 + 双频 Wi-Fi 6 (2.4/5GHz)，RISC-V。[KNOWN, HIGH]
- 开发板：ESP32-C5-DevKitC-1（USB 供电/调试）。[KNOWN, MED]
- P5 跟随验证：DevKit + USB 充电宝。[D10]

### 5.2 软件栈
- ESP-IDF；BLE 主机栈用 **NimBLE**（BLE-only 更轻）。[KNOWN, MED]
- **P1 go/no-go**：C5 的 BLE 外设/扩展广播成熟度未验证。[GUESS, LOW] 必须实测。

### 5.3 能力边界
支持：被动监听、主动扫描、GATT 连接、扩展/周期广播、Coded PHY。
不支持：经典蓝牙、AoA/AoD 测向、读取已连接设备加密流量。
