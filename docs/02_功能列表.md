# 02 · 功能列表

版本 v0.2 · 2026-10-15

优先级：**P0** 必须（MVP 基线）· **P1** 应该做 · **P2** 可做 · **X** 明确不做。

---

## P0 — 必须

| 编号 | 功能 | 说明 | 验收要点 | 阶段 |
|---|---|---|---|---|
| F1 | BLE 被动广播监听 | 抓 advertising + scan response 原始 AD 结构 | 稳定抓到周围设备广播 | P1 |
| F2 | BLE 主动扫描 | 发 SCAN_REQ 取完整广播数据 | 能拿到 scan response 字段 | P4 |
| F3 | AD 报文解析器 | 解析 AD type：Flags / 名称 / TX Power / 服务 UUID / 厂商数据 | 逐字段正确拆分，含长度越界校验 | P2 |
| F4 | 厂商库查询 | 内嵌 Bluetooth SIG 16-bit Company ID 表 | 给定 ID 查出厂商名 | P2 |
| F5 | Apple 识别 | Company ID == 0x004C | 标出"自述为 Apple" | P3 |
| F6 | Apple Continuity 子类型分类 | 按载荷首字节分类（iBeacon/AirDrop/AirPods 配对/Handoff/Nearby/Find My…） | 分类正确（编码表待实测校准，见 O3） | P3 |
| F7 | 追踪器特征识别 | Find My / Tile / SmartTag 等已知签名 | 列出追踪器候选 | P3 |
| F8 | 串口结构化输出 | **NDJSON，一行一包**（D11）：t/addr/rssi/厂商/类型/子类型 | 可被脚本逐行解析 | P2 |
| F9 | 观测记录 | 每条观测带时间戳 + RSSI | 时间戳单调、RSSI 同源 | P2 |

> 注：`main/main.c` 已实现 F1/F2（主动扫描，`ACTIVE_SCAN` 开关）/F3/F4/F5/F6/F7/F8/F9 + 设备汇总 + F11/F14（RAM 窗口 + 按 FindMy 公钥的身份键）。厂商表由 SIG PDF 生成 4048 条（O6 关闭）。Apple 子类型 0x02/0x10/0x12 实测确认。输出为 5s 周期设备快照。
>
> **F12 降级为信息项、F13 告警已移除**（2026-10-15，见 docs/06 R9）：普通 Apple 设备也发 FindMy 广播，无法与 AirTag 区分，告警会大面积误报。`follow`/`warn` 字段改为中性的 `near_persist`。

## P1 — 应该做

| 编号 | 功能 | 说明 | 阶段 |
|---|---|---|---|
| F10 | GATT 连接 + 服务/特征枚举 | 对可疑设备深挖服务 | P4 |
| F11 | RAM 滚动窗口存在性追踪 | 已实现（设备表 first/last/count/rssi 极值） | ✅ |
| F12 | "跟随我"启发式判定 | **降级为信息项 `near_persist`**（无法区分 AirTag/普通 Apple 设备，R9） | ✅ 降级 |
| F13 | 告警输出 | **已移除**（误报不可用，R9）。执行器接口仍可后续预留 | ❌ 删 |
| F14 | MAC 轮换感知的身份键 | **已实现**：按 FindMy 公钥做身份（fmkey），实测 life_ms 可累积 | ✅ |

## P2 — 可做

| 编号 | 功能 | 说明 | 阶段 |
|---|---|---|---|
| F15 | 扩展/周期广播 + Coded PHY | 扩距离、取更多广播 | P4 |
| F16 | 过滤 / 白名单 | 按厂商 / 服务 UUID 过滤 | P4 |
| F17 | 串口命令配置 | 运行期调参，不重刷固件 | P6 |

## X — 明确不做

X1 经典蓝牙 · X2 AoA 测向 · X3 解密 Apple 加密载荷 · X4 持久历史（本版）· X5 云/App。

## 功能 → 输出字段映射（供 P2 实现对照）

| 输出字段 | 来源 | 实现阶段 |
|---|---|---|
| `t` | `esp_timer_get_time()` / 1000（ms） | P1 ✅ |
| `type` / `evt` | GAP 事件类型 | P1 ✅ |
| `addr` / `at` | 广播源地址 / 地址类型 | P1 ✅ |
| `rssi` | 接收信号强度 | P1 ✅ |
| `data` | 原始 AD payload（hex） | P1 ✅ |
| `flags` | AD type 0x01 | P1 ✅ |
| `name` | AD type 0x08/0x09 | P1 ✅ |
| `tx` | AD type 0x0A | P1 ✅ |
| `co` | AD type 0xFF 前两字节（厂商 ID） | P1 ✅（仅 ID） |
| `vendor` | Company ID → 厂商名 | P2 |
| `atype` | 分类：apple/tracker/other | P3 |
| `subtype` | Apple Continuity 子类型 | P3 |
| `svc` | 服务 UUID 列表 | P2 |
